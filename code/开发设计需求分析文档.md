# 上市公司招聘信息检索系统 —— 开发设计需求分析文档

---

## 一、项目概述

### 1.1 项目背景

本项目是"信息检索系统实验"课程的期末综合大作业。项目要求以 2 人小组为单位，综合运用信息检索理论课与实践课的全部知识，针对某一特定类型资源，完成一个信息检索系统的设计与开发。

经过对多种数据资源的调研与评估，本组选择**中国 A 股上市公司招聘发布数据**作为系统的数据资源基础，构建一个面向求职者与行业研究者的垂直领域招聘信息检索系统。

### 1.2 项目目标

本项目力求在以下三个维度做到完整的知识覆盖与能力体现：

1. **理论课知识融合**：系统性地涵盖信息的存储与组织、信息的检索、信息的展示三大核心模块，具体涉及布尔逻辑检索、向量空间模型（VSM）、文献-语词矩阵、倒排文档检索、加权检索（TF-IDF 标引加权）、检索评价指标（P/R/F1/mAP）等核心知识点。
2. **实践课实验整合**：将六次实验任务（N-gram 字词统计与分析、分词规范学习与人工精标、自动分词算法实现与迭代优化、无监督关键词抽取、文本自动分类、无监督文本聚类）完整嵌入到数据处理与系统构建的全链路中。
3. **产品设计方法论贯彻**：遵循以用户为中心的产品设计五层模型（战略层 → 范围层 → 结构层 → 框架层 → 表现层），确保系统不仅是技术实验的堆砌，更是一个具备合理用户体验的完整信息产品。

### 1.3 选题说明

选择上市公司招聘数据作为检索系统资源，原因如下：

- **资源类型聚焦**：区别于课堂上已充分使用的人民日报新闻语料，招聘数据属于结构化与非结构化混合的文本，具有不同的语言学特征与信息组织逻辑，符合"探索更丰富内容"的要求。
- **语料规模适中**：原始数据约 93,602 条、81 个行业、8,796 家企业，规模足以支撑有意义的 N-gram 统计、分类与聚类实验，同时又在个人开发的可控范围内。
- **实际应用价值**：招聘信息检索是真实世界中高频使用的信息检索场景，系统可以模拟智联招聘、BOSS 直聘等产品的核心检索逻辑，具有较强的展示效果和实践意义。
- **知识覆盖全面**：招聘数据天然包含结构化字段（行业、城市、月薪、学历等）与非结构化文本（职位描述），为信息组织、多字段联合检索、文本挖掘等提供了丰富的研究维度。

### 2.3 数据预处理需求

| 预处理任务 | 具体内容 | 关联课程知识 |
|------------|----------|------------|
| 编码转换 | GBK → UTF-8，确保后续处理兼容 | 实验一 |
| 缺失值处理 | 检查各字段缺失情况，制定填充/剔除策略 | - |
| 文本清洗 | 去除职位描述中的 URL、公众号广告、特殊符号、多余空白 | 实验一 正则清洗 |
| 月薪异常值检测 | 识别最低月薪 > 最高月薪等逻辑矛盾记录 | - |
| 学历要求标准化 | "本科及以上"/"本科"/"学士" 等表述归一化 | 实验二 |
| 经验要求标准化 | "2年及以上"/"两年以上"/"2年以上" 等统一格式 | 实验二 |
| 日期格式统一 | 统一为 YYYY-MM-DD 格式 | - |
| 招聘结束日期生成 | 基于招聘发布日期 + 2个月（约60天）自动生成 | - |
| 城市名称标准化 | 处理"上海"/"上海市"等表述，统一为标准城市名 | 实验二 |
| 行业分类校验 | 检查81类行业的覆盖完整性与分类合理性 | 实验五 |

### 2.4 语料特征分析（N-gram 统计层面）

在数据预处理完成后，参考实验一的方法进行以下宏观与微观分析：

- **齐普夫定律验证**：对职位描述文本的分词结果进行词频统计与排名排序，验证词频 × 排名 ≈ 常数的分布规律。
- **N-gram 频次分布**：分别计算 unigram、bigram、trigram 的频次特征，观察随 N 增大时的数据稀疏性衰减规律。
- **高频虚词分析**：识别在招聘文本中高频但无检索价值的停用词（如"要求"、"负责"、"相关"等），构建招聘领域专属停用词表。
- **行业差异词汇**：横向对比不同行业的高频特征词，分析各行业招聘文本的词汇使用特征。

## 三、战略层设计 —— 产品目标与用户需求

### 3.1 产品目标（我们通过产品想获得什么）

1. **学术目标**：完成信息检索课程综合实验要求，完整展现信息组织、检索、展示三阶段以及六次实验的全部知识应用。
2. **能力目标**：掌握从数据预处理到系统开发到评测迭代的完整信息检索系统构建流程。
3. **展示目标**：产出一个可演示、可交互的 Web 检索系统，能够直观地呈现上市公司招聘数据的全貌。

### 5.1 交互设计 —— 核心用户流程

## 八、信息检索核心技术方案 —— 课程知识融合

### 8.1 信息的存储与组织

#### 8.1.1 倒排索引构建

对应教材第 3 章"顺排文档与倒排文档的检索"。

**构建流程：**

```
原始文档集（职位描述文本）
    ↓ CRF 分词 + 去停用词
词条序列
    ↓ 按 (词条, 文档ID, 词频, 位置) 组织
倒排索引
    ↓ TF-IDF 加权
加权倒排索引（用于 VSM 检索）
```

**索引结构设计：**

| 组件 | 数据结构 | 说明 |
|------|----------|------|
| 词典 (Lexicon) | `{词条 → (文档频率DF, 偏移量)}` | 存储所有唯一词条及其文档频率 |
| 倒排列表 (Posting List) | `[(文档ID, 词频TF, 位置列表)]` | 每个词条对应的文档级信息 |
| 文档向量库 | `{文档ID → TF-IDF稀疏向量}` | 用于余弦相似度快速计算 |

#### 8.1.2 TF-IDF 加权标引

对应教材第 6 章"逆文献频率加权标引法"。

采用 **ltc 加权公式**（对文档向量）：
- 词频因子 (TF)：对数归一化 `1 + log(tf)`
- 逆文档频率 (IDF)：`log(N/df)`
- 余弦归一化：最终向量做 L2 归一化

对于"招聘岗位"标题字段，赋予 **2.0 倍权重加成**（参考实验四"处于新闻标题中的词汇赋予 2.0 权重加成"的方法），使匹配到标题的结果获得更高的相似度得分。

### 8.2 信息的检索

#### 8.2.1 多字段联合检索策略

| 检索字段 | 匹配方式 | 权重 |
|----------|----------|------|
| 招聘岗位（标题） | TF-IDF VSM 余弦相似度 | 权重 × 2.0 |
| 职位描述（正文） | TF-IDF VSM 余弦相似度 | 权重 × 1.0 |
| 企业名称 | 精确/模糊字符串匹配 | 布尔加分 |
| 行业 | 精确分类匹配 | 布尔过滤 |
| 城市 | 精确分类匹配 | 布尔过滤 |
| 学历 | 分类匹配 | 布尔过滤 |
| 经验 | 分类匹配 | 布尔过滤 |
| 薪资范围 | 数值区间匹配 | 布尔过滤 |

**最终得分公式：**

```
Score = α × sim_title(query, title) + β × sim_desc(query, desc) + γ × bonus_company_match
其中: α = 0.5, β = 0.4, γ = 0.1
```

#### 8.2.2 向量空间模型与余弦相似度

对应教材第 2 章"向量空间模型"和"文献-语词矩阵"。

- 构建查询向量 q 和文档向量 d_j 的 TF-IDF 表示
- 计算相似度：`sim(q, d_j) = (q · d_j) / (|q| × |d_j|)`
- 按相似度降序排序，返回 Top-K 结果

#### 8.2.3 布尔检索辅助

所有结构化字段（行业、城市、学历、经验、薪资范围、日期范围）的筛选均转换为布尔逻辑表达式，如：

```
(行业 = "软件和信息技术服务业" OR 行业 = "计算机、通信...")
AND (城市 = "北京" OR 城市 = "上海")
AND (学历 = "本科" OR 学历 = "硕士")
AND 最低月薪 >= 10000
```

布尔筛选在倒排索引的全文检索结果集上进一步过滤。

### 8.4 实验一融合 —— N-gram 字词统计与宏微观分析

| 融合节点 | 具体做法 |
|----------|----------|
| 数据预处理阶段 | 对全体职位描述文本执行 unigram/bigram/trigram 字级与词级频次统计 |

| 行业对比 | 选取 Top-5 行业，对比各行业高频特征词的差异，产出一份行业词汇差异分析（可附录形式入报告） |

| 融合节点 | 具体做法 |
|----------|----------|

| 职位描述规范 | 针对招聘文本中常见的特殊切分问题（如"15k-30k"、"C++"、"Python/Java"、"五险一金"等）制定招聘领域分词规范 |
| 评测脚本 | 编写 BIES 字符级序列标注评测脚本，计算 P/R/F1 用于对比不同分词器的效果 |

### 8.6 实验三融合 —— 自动分词算法实现

| 融合节点 | 具体做法 |
|----------|----------|
| 机械分词 | 实现 FMM、BMM、BiMM 三种机械分词算法（复用实验三代码） |

| 倒排索引用分词器 | 系统主索引采用 CRF 分词器结果（实验三结论：CRF F1=84.28%，表现最优） |
| 末登录词处理 | 针对招聘领域专有名词（如"宁德时代"、"电芯"、"FA分析"），构建领域词典辅助分词 |

### 8.7 实验四融合 —— 无监督关键词抽取

| 融合节点 | 具体做法 |
|----------|----------|
| 三算法并行 | 对每条职位描述同时运行 TF-IDF、TextRank（窗口=5, 阻尼=0.85）、LDA（主题数=10）三算法 |
| 标题加权 | 招聘岗位名称中的词汇赋予 2.0 倍 TF-IDF 权重加成（复用实验四创新点） |
| Pooling 排名 | 对三算法的 Top-15 输出进行交集/并集 Pooling，取综合排名作为最终关键词 |
| 关键词标签云 | 在详情页展示每条职位的关键词标签；在统计页按行业聚合展示行业级关键词词云 |
| 专属停用词 | 屏蔽"岗位职责""任职要求""www"等招聘文本高频无意义词 |

### 8.8 实验五融合 —— 文本自动分类

| 融合节点 | 具体做法 |
|----------|----------|
| 分类任务定义 | 以"上市公司行业"（81类）作为分类标签，以"职位描述"文本作为输入特征，构建有监督分类任务 |
| 特征工程 | 8:2 分层抽样 → 仅训练集计算 IDF → 每文档取 Top-200 TF-IDF 关键词 → 稀疏向量字典 |
| 三种分类器 | 实现 KNN（K=30, 余弦距离）、朴素贝叶斯（对数转换防溢出）、线性 SVM（稀疏矩阵训练） |
| 消融实验 | 对比 Jieba vs CRF 分词对分类器性能的影响（复用实验五方法） |
| 结果展示 | 在详情页展示分类预测结果：原始行业标签 vs 模型预测标签 + 置信度 |
| 评测报告 | 计算各分类器的精确率/召回率/F1（宏观+微观），选取最优模型用于在线展示 |

### 8.9 实验六融合 —— 无监督文本聚类

| 融合节点 | 具体做法 |
|----------|----------|
| 全组合网格搜索 | 控制变量：分词路径（Jieba/CRF）× 特征抽取（TF-IDF/TextRank）= 4组数据源；聚类侧遍历 K-Means（random/k-means++/Buckshot）+ 等级聚类（Ward/Single/Complete） |
| 最佳 K 值确定 | 肘部法则 + 轮廓系数 + 均衡比 + 有效簇比例，确立最佳聚类数 |
| 冠军模型选取 | 综合内部评价得分，选出最优参数组合 |
| 聚类可视化 | 将 TF-IDF 向量降维（PCA/t-SNE）至 2D，在聚类视图页用散点图展示，不同簇用不同颜色标注 |
| 簇关键词 | 提取每个簇的高频关键词作为簇标签，展示在可视化图旁 |
| 共识标记 | 多个冠军模型共识一致的样本作为高置信度样本，在展示中标注 |

## 九、系统技术架构

### 9.1 技术选型

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端框架 | Streamlit / Flask + HTML/CSS/JS | 两选一。Streamlit 开发效率高，适合数据密集型应用；Flask 更灵活，可完全自定义前端 |
| 后端语言 | Python 3.10+ | 与实验课程技术栈一致 |
| 分词工具 | Jieba + 自研 CRF 分词器 | Jieba 用于在线快速分词，CRF 用于离线高质量分词 |
| 数据处理 | Pandas + NumPy | 数据清洗、统计、特征矩阵构建 |
| 机器学习 | Scikit-learn | TF-IDF 向量化、KNN/NB/SVM 分类器、K-Means 聚类 |
| 特征降维 | PCA / t-SNE | 聚类结果降维可视化 |
| 数据可视化 | ECharts / Plotly / Matplotlib | 统计图表、聚类散点图、Zipf 曲线 |
| 倒排索引 | 自建 Python 实现 | 基于 dict + list 的内存索引，支持布尔检索 + VSM 检索 |
| 数据库 | SQLite / 内存存储 | 93k 条数据规模适中，轻量方案即可，无需 MySQL/ES |
| 版本管理 | Git + GitHub | 代码管理与协作 |

### 9.3 数据流

```
原始CSV (GBK, 93k条, 23字段)
    ↓ [预处理]
清洗后CSV (UTF-8, ~93k条, 13字段 + 人工结束日期)
    ↓ [离线计算]
    ├── CRF 分词 → 倒排索引 (pickle)
    ├── TF-IDF 向量矩阵 (scipy sparse)
    ├── 关键词库 (json)
    ├── 分类模型 (joblib) — KNN/NB/SVM
    ├── 聚类模型 + 降维坐标 (joblib + json)
    ├── N-gram 统计数据 (json)
    └── 多维度统计摘要 (json)
    ↓ [系统加载]
Web 检索系统
    ├── 在线：关键词查询 → 倒排索引检索 → TF-IDF 排序 → 结果返回
    ├── 在线：分类预测 → 加载预训练模型 → 即时推理
    └── 展示：读取预计算的统计/聚类/词云数据 → 可视化渲染
```
