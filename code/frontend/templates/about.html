关于本系统

系统简介

上市公司招聘信息检索系统，是"信息检索系统实验"课程的期末综合大作业。系统以中国 A 股上市公司招聘发布数据为基础，构建面向求职者与行业研究者的垂直领域招聘信息检索平台。

系统综合运用了信息检索理论课（信息的存储与组织、信息的检索、信息的展示）和实践课（N-gram 分析、分词评测、关键词抽取、文本分类、文本聚类）的全部知识。

数据来源

数据名称上市公司招聘数据 2026
数据规模5,000 条（原始 93,602 条中清洗抽样）
行业分类9 大行业（从原始 81 类归并）
覆盖企业8,796 家 A 股上市公司
数据字段14 个字段（企业名称/股票简称/行业/城市/月薪/学历/经验/描述等）

技术架构

前端框架Flask + Jinja2 + ECharts
分词器CRF 条件随机场 (F1=74.77%)
信息组织倒排索引 (Lexicon + Posting List, 38,288 词条)
检索模型VSM + TF-IDF 加权 + 布尔逻辑过滤
文本分类朴素贝叶斯 (9 类, 微观 F1=25%)
文本聚类K-Means 词汇聚类 (10 个技能族群)
关键词抽取TF-IDF (F1=44.61%) + TextRank (F1=41.92%) Pooling
存储CSV + Pickle + JSON, 内存加载

AI 参与声明

个人实现部分：数据处理策略制定、分词评测标准设计、检索算法核心逻辑、分类/聚类实验变量控制、评测指标体系设计、系统架构设计。

AI 辅助部分：前端 HTML/CSS 模板生成、ECharts 图表配置代码、部分 Python 辅助代码、代码 Debug 辅助、文档格式化。
