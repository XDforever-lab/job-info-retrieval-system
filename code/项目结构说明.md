# 项目目录结构说明

```
recruit/                                          # 🏠 课程资料根目录
│
├── 📋 提示词                                      # 大作业需求提示词（你写的）
├── 📋 分词提示词                                   # 分词任务专项提示词
├── 📋 课程录音.md                                  # 老师课堂要求转录
├── 📋 处理过程记录.txt                              # 400条抽样+分词处理记录
├── 📄 期末实验 信息检索系统设计与开发.pptx            # 课程PPT（19页）
├── 📄 南京农业大学...pdf                            # 语料标注规范参考
├── 📋 ToDoList.md                                 # 340项完整任务清单
│
├── 🔧 .gitignore                                  # Git 忽略规则（CSV/模型/缓存不入库）
│
└── code/                                          # ⭐ 项目代码主目录
    │
    ├── 📄 开发设计需求分析文档.md                    # 需求分析文档（战略→表现层5层设计）
    ├── 📄 项目结构说明.md                           # 📍 你正在看的文件
    │
    ├── ⚙️ config.py                               # 全局配置文件
    │   #   所有路径、检索参数、模型参数的统一入口
    │   #   其他模块通过 from config import * 引用
    │

    │   #   用 pip install -r requirements.txt 一键安装
    │
    ├── 📁 data/                                   # 原始数据存放
    │   #   存放从外部获取的 CSV 等原始数据文件
    │   #   这些文件体积大（84MB+），已被 .gitignore 排除
    │   #   示例：上市公司招聘数据2026.csv
    │   #   ⚠️ 只读！不要直接修改原始数据
    │
    ├── 📁 src/                                    # 后端逻辑源码
    │   #
    │   ├── __init__.py                            # 包初始化
    │   ├── data_info.py                           # 数据探索报告（可直接运行）
    │   #
    │   ├── 📁 common/                             # 🟢 公共工具（前后端共用）
    │   │   ├── __init__.py
    │   │   └── data_loader.py                     # 数据加载：load_raw_data() / detect_encoding()
    │   #

    │   │   ├── 1_data_exploration.py              # 阶段2: 数据探索
    │   │   ├── 2_preprocess.py                    # 阶段2: 字段筛选+日期生成
    │   │   ├── 3_data_cleaner.py                  # 阶段2: 文本清洗+标准化
    │   │   ├── 4_sample_and_tokenize.py           # 阶段3: 200条抽样+Jieba预分词
    │   │   ├── 5_fix_tokenize_keep_punct.py       # 阶段3: 分词结果标点修正
    │   │   ├── 6_prep_seg_data.py                 # 阶段3: 分词评测数据准备
    │   │   ├── 7_segment_and_evaluate.py          # 阶段3: 7种分词器实现+评测
    │   │   ├── 8_full_crf_segment.py              # 阶段3: CRF全量5k分词
    │   │   ├── 9_ngram_analysis.py                # 阶段4: N-gram+Zipf验证
    │   │   ├── 10_keyword_extraction.py           # 阶段5: TF-IDF+TextRank关键词
    │   │   ├── 11_keyword_eval_and_export.py      # 阶段5: 关键词评测+导出
    │   │   ├── 12_classification_prep.py          # 阶段6: 400条分类样本标注
    │   │   ├── 13_classification_model.py         # 阶段6: NB+KNN分类器训练评测
    │   │   ├── 14_save_model_and_predict.py       # 阶段6: 模型持久化+预测接口
    │   │   ├── 15_clustering.py                   # 阶段7: K-Means词汇聚类
    │   │   └── 16_similar_jobs.py                 # 阶段7: 相似岗位推荐+矩阵保存
    │   #
    │   ├── 📁 post_midterm/                       # 🔴 中期后（阶段8+，待开发）

    │   │   └── predictor.py                       # 分类预测接口封装

    │   └── 📁 ppt/                                # PPT生成脚本
    │       ├── make_ppt.py
    │       ├── build_ppt.py
    │       ├── build_magazine_ppt.py
    │       └── generate_ppt.py
    │

    │   #   系统的用户界面，基于 Flask 框架
    │   #
    │   ├── __init__.py                            # 包初始化
    │   ├── app.py                                 # Flask 主应用 🌟 启动入口

    │   │   ├── detail.html                        # 职位详情页

    │   │   ├── cluster.html                       # 聚类视图页
    │   │   └── about.html                         # 关于页
    │   │
    │   └── 📁 static/                             # 静态资源
    │       ├── 📁 css/
    │       │   └── style.css                      # 全局样式表
    │       ├── 📁 js/
    │       │   └── main.js                        # 前端交互脚本
    │       └── 📁 img/                            # [可选] 图片资源

    ├── 📁 models/                                 # 离线训练模型存放
    │   #   存放训练好的模型文件，系统启动时加载到内存
    │   #   文件格式: .pkl (pickle) / .joblib / .npz (稀疏矩阵)

    │   #   test_classifier.py    —— 分类器测试
    │   #   test_evaluator.py     —— 评测逻辑测试
    │
    └── 📁 docs/                                    # 项目文档
        #   存放补充说明文档、会议记录、设计草稿等
        #   与根目录的区别：docs/ 是过程文档，根目录是最终提交物
```

## 各阶段开发对应的文件

| 开发阶段 | 涉及的源文件 | 涉及的 output/ 文件 | 涉及的前端页面 |
|----------|-------------|--------------------|---------------|
| 数据预处理 | `common/data_loader.py` `pre_midterm/1-3` | `*_processed.csv` `stopwords.txt` | — |
| N-gram 分析 | `pre_midterm/9_ngram_analysis.py` | `ngram_report.json` | `about.html` |
| 分词实验 | `pre_midterm/4-8` | `seg_eval_*` `*_segmented.csv` | `detail.html`（分词对比弹窗） |
| 关键词抽取 | `pre_midterm/10-11` | `*_keywords.json` `agg_*.json` | `detail.html`（标签）+ `stats.html`（词云） |
| 文本分类 | `pre_midterm/12-14` | 模型 → `models/` | `detail.html`（分类预测） |
| 词汇聚类 | `pre_midterm/15-16` | `word_cluster_*` `similar_jobs.json` | `cluster.html` |
| 倒排索引 | `post_midterm/indexer.py` | `inverted_index.pkl` → `models/` | — |
| 检索引擎 | `post_midterm/search_engine.py` | — | `search.html` + `index.html` |
| 关键词高亮 | `post_midterm/highlighter.py` | — | `search.html` + `detail.html` |
| 分类预测 | `post_midterm/predictor.py` | — | `detail.html` |

## 如何启动项目

```bash
# 1. 激活环境
conda activate my_project

# 2. 安装依赖（首次）
pip install -r requirements.txt

# 3. 运行数据探索（了解数据）
python src/data_info.py

# 4. 启动 Web 系统
python frontend/app.py

# 5. 打开浏览器访问
# http://localhost:5000
```

## 文件命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| Python 模块 | 小写 + 下划线 | `data_loader.py` `search_engine.py` |
| 配置文件 | 小写 | `config.py` |
| HTML 模板 | 小写 + 下划线 | `index.html` `search.html` |
| CSS/JS | 小写 + 下划线 | `style.css` `main.js` |
| 数据文件 | 中文描述 + 英文后缀 | `上市公司招聘数据2026.csv` |
| 测试文件 | `test_` 前缀 | `test_search.py` |
| 模型文件 | 小写 + 下划线 | `classifier.joblib` |
