# 项目目录结构说明

```
recruit/                                          # 🏠 课程资料根目录
│
├── 📋 提示词                                      # 大作业需求提示词（你写的）
├── 📋 分词提示词                                   # 分词任务专项提示词
├── 📋 课程录音.md                                  # 老师课堂要求转录
├── 📋 处理过程记录.txt                              # 400条抽样+分词处理记录
├── 📄 期末实验 信息检索系统设计与开发.pptx            # 课程PPT（19页）
├── 📄 南京农业大学...pdf                            # 语料标注规范参考
├── 📋 ToDoList.md                                 # 340项完整任务清单
│
├── 🔧 .gitignore                                  # Git 忽略规则（CSV/模型/缓存不入库）
│
└── code/                                          # ⭐ 项目代码主目录
    │
    ├── 📄 开发设计需求分析文档.md                    # 需求分析文档（战略→表现层5层设计）
    ├── 📄 项目结构说明.md                           # 📍 你正在看的文件
    │
    ├── ⚙️ config.py                               # 全局配置文件
    │   #   所有路径、检索参数、模型参数的统一入口
    │   #   其他模块通过 from config import * 引用
    │
    ├── ⚙️ requirements.txt                        # Python 依赖清单
    │   #   用 pip install -r requirements.txt 一键安装
    │
    ├── 📁 data/                                   # 原始数据存放
    │   #   存放从外部获取的 CSV 等原始数据文件
    │   #   这些文件体积大（84MB+），已被 .gitignore 排除
    │   #   示例：上市公司招聘数据2026.csv
    │   #   ⚠️ 只读！不要直接修改原始数据
    │
    ├── 📁 src/                                    # 后端逻辑源码
    │   #   所有的 Python 业务逻辑都放在这里
    │   #   每个 .py 文件是一个独立的功能模块
    │   #
    │   ├── __init__.py                            # 包初始化（空文件，标识为 Python 包）
    │   ├── data_loader.py                         # 数据加载与预处理工具
    │   #   #   提供 load_raw_data() / detect_encoding() / get_data_summary()
    │   ├── data_info.py                           # 数据探索报告脚本（可直接运行）
    │   #   #   运行 python src/data_info.py 查看数据全貌
    │   ├── preprocess.py                          # [待开发] 数据清洗与标准化
    │   │   #   字段筛选、缺失值处理、文本清洗、学历/经验/城市标准化
    │   ├── segmenter.py                           # [待开发] 分词模块
    │   │   #   Jieba 分词 + CRF 分词 + FMM/BMM 机械分词
    │   ├── keywords.py                            # [待开发] 关键词抽取
    │   │   #   TF-IDF / TextRank / LDA 三算法 + Pooling 融合
    │   ├── classifier.py                          # [待开发] 文本分类
    │   │   #   KNN / 朴素贝叶斯 / SVM 训练与预测
    │   ├── cluster.py                             # [待开发] 文本聚类
    │   │   #   K-Means / 等级聚类 + 降维可视化数据生成
    │   ├── indexer.py                             # [待开发] 倒排索引构建
    │   │   #   词典构建 + 倒排列表 + TF-IDF 加权 + 序列化存储
    │   ├── search_engine.py                       # [待开发] 检索引擎
    │   │   #   查询解析 → 布尔过滤 → VSM 相似度排序 → 结果返回
    │   ├── evaluator.py                           # [待开发] 评测模块
    │   │   #   检索评测（P@10/MAP/NDCG）+ 分类/聚类/分词评测
    │   └── ngram_analyzer.py                      # [待开发] N-gram 统计分析
    │       #   Unigram/Bigram/Trigram 频次 + Zipf 验证 + 停用词提取
    │
    ├── 📁 frontend/                               # Flask Web 前端
    │   #   系统的用户界面，基于 Flask 框架
    │   #
    │   ├── __init__.py                            # 包初始化
    │   ├── app.py                                 # Flask 主应用 🌟 启动入口
    │   │   #   运行: python frontend/app.py
    │   │   #   包含 7 个页面路由 + RESTful API 接口
    │   │
    │   ├── 📁 templates/                          # Jinja2 HTML 模板
    │   │   #   每个 .html 对应系统的一个页面
    │   │   ├── base.html                          # 基础模板（导航栏+页脚，所有页面继承它）
    │   │   ├── index.html                         # 首页 —— 搜索门户
    │   │   ├── search.html                        # 检索结果页
    │   │   ├── detail.html                        # 职位详情页
    │   │   ├── industry.html                      # 行业浏览页
    │   │   ├── stats.html                         # 数据统计页（图表）
    │   │   ├── cluster.html                       # 聚类视图页
    │   │   └── about.html                         # 关于页
    │   │
    │   └── 📁 static/                             # 静态资源
    │       ├── 📁 css/
    │       │   └── style.css                      # 全局样式表
    │       ├── 📁 js/
    │       │   └── main.js                        # 前端交互脚本
    │       └── 📁 img/                            # [可选] 图片资源
    │
    ├── 📁 models/                                 # 离线训练模型存放
    │   #   存放训练好的模型文件，系统启动时加载到内存
    │   #   文件格式: .pkl (pickle) / .joblib / .npz (稀疏矩阵)
    │   #   已被 .gitignore 排除（体积大，可重新训练生成）
    │   #
    │   #   预期文件：
    │   #   inverted_index.pkl    —— 倒排索引
    │   #   tfidf_matrix.npz      —— TF-IDF 文档向量矩阵
    │   #   vocab_map.json        —— 词汇→维度索引映射
    │   #   classifier.joblib     —— 最优分类器模型
    │   #   cluster.joblib        —— 最优聚类模型
    │   #   keywords.json         —— 全量关键词库
    │
    ├── 📁 output/                                  # 中间产出与结果文件
    │   #   存放数据处理过程中产生的中间文件
    │   #   与 data/ 的区别：data/ 是原始输入，output/ 是加工产出
    │   #
    │   #   预期文件：
    │   #   stopwords.txt              —— 招聘领域停用词表
    │   #   ngram_report.json          —— N-gram 分析报告
    │   #   stats_summary.json         —— 多维度统计摘要
    │   #   cluster_vis.json           —— 聚类可视化数据
    │   #   eval_report.json           —— 评测报告
    │   #   上市公司招聘数据_processed.csv  —— 清洗后的全量数据
    │   #   上市公司招聘数据_segmented.csv  —— 分词后的全量数据
    │   #   上市公司招聘数据_抽样400条_分词_校对.csv  —— [已存在] 抽样分词结果
    │
    ├── 📁 tests/                                   # 测试代码
    │   #   所有自动化测试脚本放这里
    │   #   命名规范: test_<被测模块>.py
    │   #
    │   #   预期文件：
    │   #   test_data_loader.py   —— 数据加载测试
    │   #   test_segmenter.py     —— 分词效果测试
    │   #   test_search.py        —— 检索功能测试
    │   #   test_classifier.py    —— 分类器测试
    │   #   test_evaluator.py     —— 评测逻辑测试
    │
    └── 📁 docs/                                    # 项目文档
        #   存放补充说明文档、会议记录、设计草稿等
        #   与根目录的区别：docs/ 是过程文档，根目录是最终提交物
```

## 各阶段开发对应的文件

| 开发阶段 | 涉及的 src/ 文件 | 涉及的 output/ 文件 | 涉及的前端页面 |
|----------|-----------------|--------------------|---------------|
| 数据预处理 | `data_loader.py` `preprocess.py` | `*_processed.csv` `stopwords.txt` | — |
| N-gram 分析 | `ngram_analyzer.py` | `ngram_report.json` | `about.html`（展示） |
| 分词实验 | `segmenter.py` | — | `detail.html`（分词对比弹窗） |
| 关键词抽取 | `keywords.py` | `keywords.json` | `detail.html`（标签区）+ `stats.html`（词云） |
| 文本分类 | `classifier.py` | 模型 → `models/` | `detail.html`（分类预测区） |
| 文本聚类 | `cluster.py` | `cluster_vis.json` | `cluster.html` |
| 倒排索引 | `indexer.py` | `inverted_index.pkl` → `models/` | — |
| 检索引擎 | `search_engine.py` | — | `search.html` + `index.html` |
| 系统评测 | `evaluator.py` | `eval_report.json` | `about.html`（评测报告） |

## 如何启动项目

```bash
# 1. 激活环境
conda activate my_project

# 2. 安装依赖（首次）
pip install -r requirements.txt

# 3. 运行数据探索（了解数据）
python src/data_info.py

# 4. 启动 Web 系统
python frontend/app.py

# 5. 打开浏览器访问
# http://localhost:5000
```

## 文件命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| Python 模块 | 小写 + 下划线 | `data_loader.py` `search_engine.py` |
| 配置文件 | 小写 | `config.py` |
| HTML 模板 | 小写 + 下划线 | `index.html` `search.html` |
| CSS/JS | 小写 + 下划线 | `style.css` `main.js` |
| 数据文件 | 中文描述 + 英文后缀 | `上市公司招聘数据2026.csv` |
| 测试文件 | `test_` 前缀 | `test_search.py` |
| 模型文件 | 小写 + 下划线 | `classifier.joblib` |
