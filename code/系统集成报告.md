## 一、系统运行所需核心文件

以下文件在 Flask 启动时加载到内存，直接参与检索和页面渲染：

### 1.1 数据层

| 文件 | 大小 | 作用 |
|------|------|------|
| `output/3_cleaner/上市公司招聘数据_cleaned.csv` | ~120MB | 系统主数据源。包含 5000 条清洗后的招聘记录（14 字段），所有页面展示均从此读取 |
| `output/8_full_seg/上市公司招聘数据_segmented.csv` | ~150MB | 分词后数据。追加了 `职位描述_分词` 和 `招聘岗位_分词` 两列，供检索引擎构建倒排索引 |

### 1.2 检索引擎层

| 文件 | 大小 | 作用 |
|------|------|------|
| `models/tfidf_matrix.npz` | 5000×32365 | 全量文档 TF-IDF 稀疏矩阵。**检索核心**：用户查询先向量化，再与矩阵做余弦相似度批量计算，排序返回 |
| `models/vocab_map.json` | ~300KB | 词汇→矩阵维度索引映射。用户查询词通过此映射定位到 TF-IDF 矩阵的对应维度 |
| `output/stopwords.txt` | ~30KB | 停用词表（招聘领域专属 + 哈工大通用 + 百度通用）。查询解析时过滤无意义词 |

### 1.3 智能服务层

| 文件 | 作用 |
|------|------|
| `models/nb_classifier.joblib` | 朴素贝叶斯行业分类器（alpha=0.1，400 条训练）。**首页26→9 类行业标签**：用户点"互联网/软硬件技术"，系统展示该类别下的职位 |
| `models/classifier_vocab.json` | 分类器词汇表（DF 字典 + 训练集规模）。预测接口 `predict_industry(text)` 加载后调用 |
| `output/10_keywords/all_keywords.json` | 5000 条文档各自 Top-15 关键词。**详情页词云/标签**：展示该岗位的核心技能词，可点击标签触发二次搜索 |
| `output/16_similar/similar_jobs.json` | 5000 条 × Top-5 相似职位。**详情页底部推荐**：余弦相似度计算，本质是 VSM 检索 |
| `output/10_keywords/agg_industry.json` | 按 9 类行业聚合的关键词 Top-20。**统计页行业词云** |
| `output/10_keywords/agg_city.json` | 按城市聚合关键词。**统计页城市词云** |
| `output/10_keywords/agg_category.json` | 按招聘类别聚合关键词。**统计页类别词云** |

## 四、系统数据流

```
用户搜索 "Python 开发"
    │
    ▼
[Flask API] parse_query("Python 开发")
    │
    ├─ jieba 分词 → ["Python", "开发"]
    ├─ stopwords.txt 过滤
    │
    ▼
[models/vocab_map.json] → 词→维度映射
    │
    ▼
[models/tfidf_matrix.npz] → 查询向量 × 文档矩阵 = 余弦相似度
    │
    ▼
[布尔过滤] 行业/城市/学历/薪资/日期 ←─ output/3_cleaner/上市公司招聘数据_cleaned.csv
    │
    ▼
[排序] Top-20 → 返回结果列表
    │
    ├─ 关键词高亮 ←─ 查询词直接匹配
    ├─ 关键词标签 ←─ output/10_keywords/all_keywords.json
    ├─ 行业分类预测 ←─ models/nb_classifier.joblib
    └─ 相似推荐 ←─ output/16_similar/similar_jobs.json
```

## 六、系统启动时需加载的文件清单

```python
1. pd.read_csv('output/3_cleaner/上市公司招聘数据_cleaned.csv')
2. load_npz('models/tfidf_matrix.npz')
3. json.load('models/vocab_map.json')

5. json.load('models/classifier_vocab.json')
6. json.load('output/10_keywords/all_keywords.json')
7. json.load('output/16_similar/similar_jobs.json')
8. 停用词: open('output/stopwords.txt')
```
